# Лабораторная работа №7 — анимация

Рисунок из лабораторной №4 разбит на части с шарнирами и анимируется процедурно:
поза каждый кадр собирается заново, исходная геометрия не меняется.

## Что показано

- скелет из пяти групп: корпус, две руки, две ноги; у каждой свой шарнир;
- циклы `покой`, `ходьба`, `бег` — углы задаются синусоидой, а фактические
  значения догоняют целевые через `MathUtils.damp`, поэтому переключение плавное;
- покачивание корпуса и наклон при беге;
- визуализация шарниров (`AxesHelper`) по кнопке;
- анимация по времени кадра (`dt`), а не по номеру кадра.

## Запуск

```bash
npm install
```

Открыть корень проекта через http-сервер (встроенный сервер PhpStorm или `npx serve .`) и перейти на `index.html`.
ES-модули и import map не работают по `file://`.

## Управление

- кнопки `Покой / Ходьба / Бег`, ползунок скорости;
- `?mode=walk` в адресе открывает сразу нужный режим;
- `Показать шарниры` — оси в точках вращения;
- ЛКМ — вращение камеры, колесо — масштаб, ПКМ — сдвиг.
