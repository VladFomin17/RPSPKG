# Лабораторная работа №5 — освещение

Рисунок из лабораторной №4 (`points2D` + выдавливание) отображается в three.js и освещается по модели
Ламберта с зеркальной составляющей Блин-Фонга.

## Что показано

- три источника: рассеянный (полусферический), основной с картой теней и контровой;
- материал `MeshStandardMaterial`: цвет, шероховатость, металличность;
- переключение каркаса и автоматического вращения;
- визуализация направленных источников (`DirectionalLightHelper`);
- тени `PCFSoftShadowMap`, тонмаппинг ACES, сглаживание MSAA.

## Запуск

```bash
npm install
```

Открыть корень проекта через http-сервер (встроенный сервер PhpStorm или `npx serve .`) и перейти на `index.html`.
ES-модули и import map не работают по `file://`.

## Управление

- ЛКМ — вращение камеры, колесо — масштаб, ПКМ — сдвиг;
- ползунки и переключатели в правой панели;
- «Сбросить» возвращает значения из разметки.
