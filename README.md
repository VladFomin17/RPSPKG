# Лабораторная работа №6 — текстуры

Тот же рисунок из лабораторной №4, но с UV-развёрткой: на модель накладываются
растровые текстуры, масштабируются, фильтруются и анизотропно сглаживаются.

## Что показано

- проекционная (box) UV-развёртка: ось выбирается по доминирующей компоненте нормали;
- четыре процедурные текстуры на canvas и загрузка собственной картинки;
- повтор UV (`texture.repeat`) и анизотропная фильтрация на максимуме GPU;
- переключение билинейной и точечной фильтрации (`magFilter`);
- освещение как в лабораторной №5, чтобы текстура была видна в свете и тени.

## Запуск

```bash
npm install
```

Открыть корень проекта через http-сервер (встроенный сервер PhpStorm или `npx serve .`) и перейти на `index.html`.
ES-модули и import map не работают по `file://`.

## Управление

- ЛКМ — вращение камеры, колесо — масштаб, ПКМ — сдвиг;
- кнопки текстур, ползунки повтора UV и шероховатости;
- `Загрузить свою картинку` — любое изображение с диска.
