# Лабораторная работа №8 — игра

Аркада на том же рендерере, что и лабораторные 5–7: персонаж бегает по арене,
собирает кристаллы и уходит от преследователей.

## Механика

- арена радиусом 30, камера обзорная: смотрит на центр, поэтому поле видно целиком;
- перед стартом отсчёт 3 секунды — в это время противники стоят, таймер не идёт;
- WASD — движение относительно камеры, мышь — поворот камеры вокруг арены;
- 10 кристаллов, за каждый +1 очко, после сбора кристалл появляется в новом месте;
- противников от 1 до 5 (касание — поражение);
- цель от 5 до 50 кристаллов; 60 секунд на партию.

## Настройки

На стартовом экране два ползунка:

- **Противники** — 1…5, задаёт число активных преследователей;
- **Победных очков** — 5…50, сколько кристаллов нужно собрать.

Настройки применяются сразу и сохраняются при рестарте.

## Что показано

- игровой цикл `update(dt)` отдельно от рендера (`setAnimationLoop` в `createView`);
- обзорная камера с экспоненциальным сглаживанием (`Vector3.lerp`);
- ввод через `KeyboardEvent.code` и `pointermove` (мышь);
- коллизии — расстояния в плоскости XZ;
- состояния `menu → play → win/lose` и рестарт;
- скелетная анимация из лабораторной №7: персонаж переключает `покой/ходьба/бег`.

## Запуск

```bash
npm install
```

Открыть корень проекта через http-сервер (встроенный сервер PhpStorm или `npx serve .`) и перейти на `index.html`.
ES-модули и import map не работают по `file://`.

## Управление

- `WASD` / стрелки — движение, `Enter` — старт или рестарт;
- перетаскивание мышью — поворот камеры;
- `?play=1` в адресе запускает игру сразу.
